# 管理与安全

入口为「管理与安全」`/#/system/control-center`。旧「系统管理员」保留初始所有者 Passkey 与个人 TOTP；代理用户继续使用 sing-box 独立门户。

## 管理员与权限

初始登录名为 `admin`，现有密码、TOTP、Passkey 不变。所有者新增具名管理员，运维及只读管理员使用独立密码和个人 TOTP。初始所有者的 Passkey 不能被其他管理员读取、绑定或移除。新增密码至少12字节；保存角色、服务器范围或密码修改会注销该管理员会话并撤销其令牌，必须保留至少一个启用的所有者。

按服务器和功能分配权限：服务器、监控、终端、文件、服务、检测、网络配置、DNS、代理、批量运维、备份恢复、云资源与安全各自具有读写能力。只读角色不能写；后端统一拒绝未分类管理接口，不能靠直接请求绕过界面。服务器列表、搜索及导出按授权过滤；跨服务器旧聚合入口需要全服务器授权，已接入逐对象权限检查的新工作台按自己的目标集合检查。

高风险操作需要当前会话五分钟内的密码/TOTP 验证；过期时界面再次验证后重试之前被拒绝、尚未执行的请求。初始密码或 Passkey 登录本身构成刚完成的验证。交互式终端还受目标 Agent 的执行账户、目录和能力策略限制。再次验证不扩大已有授权，API 令牌不能替代管理员会话。

## 凭据引用与轮换

运行环境设置 `SINAN_CREDENTIAL_KEYS` 为「密钥标识→32字节密钥的标准 Base64」JSON，`SINAN_CREDENTIAL_CURRENT_KEY` 为当前标识。密钥由操作者在独立保管位置生成，不能提交仓库、普通日志或备份清单。缺少密钥环会明确拒绝凭据写入、解密和自动签发，不退回明文。

凭据中心保存 DNS、云账号、备份、外部 API、证书维护资料的加密正文，返回 UUID 引用。AES-256-GCM 将引用、用途和版本一并认证，复制密文到别的记录或修改版本会失败。列表仅显示名称、用途、密钥标识、版本和状态；没有普通明文读取接口。内部使用按用途核对并记录使用方审计。DNS、网络资料提供方和证书执行器通过引用使用；旧提供方配置的兼容字段需按各插件流程迁入引用，不能将中心加密等同于所有历史字段已经迁移。

「转用当前加密密钥」要求旧密钥仍在密钥环，解密并重新加密、增加版本；消费者凭据本身的替换通过版本确认接口提交新正文。停用引用会让后续消费者明确失败，不自动使用旧明文备选。恢复需要与数据库密文配套的历史密钥，备份只保存必要 key_id 和外部保管位置。

## 令牌、会话、审计与保留

令牌只显示创建时的一次原值，数据库保存摘要、能力、服务器集合、到期、撤销及最近使用。所属管理员权限与令牌范围取交集；管理员停用、撤权或令牌到期后失效。排队和定时高风险工作采用管理员会话确认，并在每次派发前重核管理员权限，不能把限权令牌提升成后台所有者任务。

会话列表支持单独注销。登录成功、密码/Passkey 登录失败和退出分别记录脱敏安全事件；受限 API 令牌不能读取交互式工作区草稿、个人二步验证或会话列表。操作审计保存主体、对象、动作、有界脱敏请求及接口返回状态，口令、令牌、私钥、命令、终端输入和文件正文不进入通用审计。服务器和节点直接修改额外保存邻近请求的前后状态；这不是事务性因果证明，对应功能的版本历史、预览摘要和执行回执才是精确变更依据。排队成功也不是设备执行成功。

监控、日志、IP 查询、终端、代理访问、审计分别配置期限。监控期限映射既有历史维护；审计、IP 缓存及观察点收据按周期清理。终端和插件访问记录按各模块清理，保留设置不等于删除活动会话、业务账本或恢复所需材料。

## 工作区与开放接口

Ctrl/⌘+K 或 `/` 打开全局搜索，Esc 关闭；可搜索有权访问的服务器、IP、节点、代理用户、DNS 域名、任务及告警规则，添加收藏或访问后保留最近入口。收藏、视图、主题、密度和基础信息草稿按管理员保存，并使用版本号拒绝覆盖另一个窗口的新内容。

服务器列表可保存名称/标签/地区筛选、在线状态、分组、排序、显示列及密度；批量选择不随筛选自动扩大，逐台维护结果单独显示，失败保留原选择。服务器详情直接进入运维、网络验机、网络证书及批量任务，沿用服务器上下文。新增服务器表单支持保存和恢复非秘密基础信息草稿，失败保留当前表单；浏览器离开未保存表单时提示。

`GET /api/control-center/export/servers` 导出授权服务器公开系统资料和指标，不包含设备身份凭据、成本或私钥。`GET /api/control-center/events?after=<id>` 以 SSE 订阅当前管理员的操作结果，游标可续接；会话或令牌失效结束连接。事件不暴露其他管理员审计和请求正文，长连接仍周期复核能力。既有管理 API 同样经过能力与范围检查。

## 系统自检与独立观察点

系统自检展示数据库连接/大小、磁盘容量、命令/诊断/通知/运维积压、后台周期心跳、最近备份的清单/完整性/恢复状态、定时备份结果、本地签名制品库存与独立观察点报告。它不默认访问外部发布源。缺失或过期心跳是未知/过期，备份和更新缺证据时不显示正常。自检页面只允许所有者会话读取。

在独立主机运行 `scripts/observe-panel.py --panel-origin https://panel.example.com --observer-name observer-a`，通过环境 `SINAN_OBSERVER_API_TOKEN` 提供仅 `monitoring:write` 的受限令牌；可由该主机的定时器安排执行。工具保留正常 TLS 验证，只检查实际 `/healthz` 响应并提交采样时间、状态和耗时。面板不可达时返回本地证据和投递失败，不能声称面板已保存；恢复后可由操作者重新提交原时间证据。未默认创建外部监控或发送真实通知。

## 工具与依赖安全建议

管理与安全页提供工作区 Cargo.lock 精确版本快照及真实本地签名制品库存。管理员显式查询 OSV 官方包版本接口，不上传私有仓库包、不自动升级。返回记录来源、查询时间、有效观察时间、建议身份和来源列出的修复版本；未记录建议、查询失败、过期结果及未支持生态分别展示。失败保留上次证据但状态保持未知，来源修复版本不代表目标运行兼容性已经验证。工作区快照包含开发依赖，不断言所有包都进入面板进程。

长表单统一草稿工具复用管理员私有偏好与版本比较。服务器资产仅保存采购、备注等字段，授权范围不进草稿；资产与授权提交还必须携带读取时的完整摘要，服务器行锁下拒绝旧快照覆盖。网络方案保留固定来源、步骤、预算和计划参数，URL、认证与请求正文省略，恢复后重新补齐；运维方案保留固定目标和 typed 步骤。提交失败保持输入，未保存修改离开时提醒；其他窗口变更须读取新草稿或远端版本后再次核对。
