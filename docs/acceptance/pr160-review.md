## 补修后的行为

- 终端输入审计不保存原始 PTY 内容，输出及输入绑定创建时的管理员和会话。当前权限、再认证和撤销在事务锁内复核；锁竞争有界拒绝，不允许旧会话继续操作。
- 本地关闭、撤销、期限和失联回收先于上报；拒绝或失败的网络事件不能延长进程寿命。临时网络写入共享私有锁，回退核对预期值，拒绝覆盖后来的人工变更；未知清理保持原身份。
- 证书写入绑定真实服务账号、私有目录 FD、原 inode 和摘要；未知账号拒绝。WireGuard 接口没有所属配置时拒绝接管，停止后补偿和迟到结果不伪造成功。
- DNS 写入先提交冻结权限、凭据版本、原记录快照和单次意图，再提交发送标记后执行有界外部请求。未知创建不猜记录 ID；未知写入互斥只允许只读核对，历史和回退同时核对原范围与当前范围。
- 运维人工核对需要新鲜且精确关联原操作的成功只读回执，不覆盖原状态、结果和摘要；迟到真实回执仍保留。隔离恢复使用独立随机数据库口令，外部工具执行和输出均有界。
- 工作台派发、领取、DNS 后及每次发送前重查冻结目标和许可，共同消费总截止。输出有界，磁盘临时文件登记后解除目录链接；清理失败保留进程身份。界面拒绝旧请求、旧对象及卸载后回调，不丢草稿或允许陈旧写入。
- CPU 硬上限能力绑定实际 `ServiceManager`，默认拒绝；仅 systemd 与当前控制器同时可用时声明。OpenRC、launchd、FreeBSD、Windows 和未知后端拒绝。模拟服务明确声明 TEST_ONLY 能力并核对预算，不代表真实控制器签收。

实施阶段未运行测试、构建、格式工具或检查器。完整实现、界面、协议、测试源码和文档先集中完成，再冻结统一验收；验收修复只替换失败或实际输入受影响的完整范围。
