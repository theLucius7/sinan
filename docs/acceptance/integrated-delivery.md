## 面板与被控服务器的业务关系

1. **服务器归 core。** Agent 注册、设备身份、心跳、遥测、服务器网卡流量和诊断生命周期属于服务器管理。系统管理员位于“系统”；代理用户不是管理员。
2. **服务器明确启用插件。** Agent 声明能力只代表支持。管理员启用 sing-box 后，面板安排签名运行时安装；下载／安装状态与配置应用确认分别展示。未启用的纯监控服务器不自动获得代理业务。
3. **节点和链路归插件。** “sing-box 插件 → 代理节点”管理直连资源、独立入口和有序链路；链路可引用受管节点或订阅来源的具体节点。来源版本、候选向量、引用保护、幂等收据及退役保持在插件与 compiler，策略页面引用已有资源。
4. **代理用户与授权归插件。** “代理用户”和“策略与套餐”分配业务身份、可访问资源及套餐；用户 ID、凭据、令牌、原订阅路径与历史流量保持兼容。数据库表没有因目录搬迁统一改名。
5. **发布依赖真实设备确认。** 面板生成完整签名配置，Agent 执行安装与对账并返回持久回执；链路发布核对精确运行实例、完整向量和恢复屏障。失败、未知及未确认不能通过生成一份配置直接变为在线。
6. **订阅和计量读取插件业务状态。** 用户订阅按授权和发布资格选择资源，不暴露中间段秘密；链路在入口计量一次。core 的服务器网卡总流量独立保留，计量 `epoch` 标记计数器重置，不替代套餐周期。

面板业务实现在 `plugins/singbox/panel/`，API 为 `/api/plugins/sing-box/...`；前端实现在 `web/src/plugins/singbox/`。Agent 入口注册适配器，`agent-core` 只负责通用身份、传输、任务、制品、对账与服务器管理。具体边界见 [ADR 0023](../adr/0023-proxy-business-boundary.md)、[ADR 0061](../adr/0061-singbox-plugin-lifecycle.md) 和 [ADR 0073](../adr/0073-ordered-path-publication-and-native-probe.md)。
