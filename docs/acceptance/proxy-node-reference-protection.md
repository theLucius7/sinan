# 代理节点删除引用保护

对应 [Issue #147](https://github.com/theLucius7/sinan/issues/147)。本轮于 2026-10-03 集中补充实现和回归源码，全部修改冻结后统一验收。前端回归、一次产品构建及下列两套实际 dist 浏览器已完成；Rust 与隔离 PostgreSQL 的最终结果随 [全部开放 issues 集成记录](all-open-issues-20261003.md) 更新，真实设备验证仍待。

## 删除合同

旧 `/api/plugins/sing-box/nodes/{id}`、数值 `/proxy-resources/direct/{id}`、有序 `/ordered-proxy-resources/direct/{id}` 与节点目录批量删除使用共同拓扑锁和引用保护。仍被策略组、旧两跳、数值混合路径或有序路径使用时，返回 409，公开清单仅包含策略／链路 ID、名称、角色、代数、跳位置及状态。每类清单至多 32 项，名称清除控制字符并限制 128 个字符；不包含订阅令牌、入口密钥、内部身份或原始快照。

有序路径保留目标、已应用、候选和恢复代的引用。任一选中不可变版本缺失时，专用入口直接按保存的路径身份返回 `unresolved`；保存的旧受管跳按保守所有权返回 `unresolved`。清单不再依赖该版本成功读回才能生成，因此损坏指针不会只得到没有清单的笼统冲突。没有入口或受管跳原始身份的任意节点不会被伪称为该路径的确定引用。

数值混合路径沿用已有全部保存跳的删除保护；非当前代的旧依赖标为 `retained`。有序正常版本中未被选中的历史代不阻止删除；完成退役才解除损坏版本的保守保护。页面接受并显示目标、历史待清理、版本损坏待确认这些状态。

完整链路资源删除继续只清理专用入口及其授权，保留共享出口、其它链路、来源、历史流量、不可变版本和创建幂等收据。旧 `/chains/{id}` 继续仅解除兼容关系，有序路径不能通过该入口降格删除。目录整批删除现在也先用共同链路／入口引用检查，策略冲突返回相同公开清单，任一冲突则整批不变。除自身路径外的引用在限制返回条数之前排除自身，避免自身历史遮住其它所有者。

退役服务器、停用／软删端点和节点协议参数损坏不阻止明确的完整资源清理。保存的链路版本或设备清理证据损坏时，仍保持既有保守退役门禁；409 中的 `unresolved` 只说明已保存所有者需要处理，不表示设备监听或身份已经撤销。

## 前端实际结果

依赖按冻结锁文件安装一次，全 Bun 回归 167 项通过、0 失败、2258 次断言；一次 TypeScript／Vite 构建成功，保留既有大于 500 kB 分块提示。`ordered-chains.mjs` 在同一构建的 dist 上完成 1440、390、320 三个宽度；`proxy-resources.mjs` 首轮在删除后的全局资源定位器触发 Playwright 严格匹配错误：目录旧快照短暂同时包含表格和响应式卡片，不能用要求唯一元素的 `waitFor` 等待消失。

修复仅涉及浏览器夹具，改为 7 秒有界等待该资源的全部实例数量归零，不选择第一项或依据隐藏布局弱化检查。冻结该修复后只补验失败的代理资源浏览器组，20.552 秒退出 0；产品源码、dist、已通过的 Bun 回归与有序路径浏览器没有修改或重复运行。原失败收据 `ui-proxy-resources` 和补验收据 `ui-proxy-resources-rerun` 分别保留，构建与其它通过结果为 `web-install`、`web-bun`、`web-build`、`ui-ordered-chains`；保留位置及最终清理状态由整体集成记录登记。

已有 [代理资源本地验收](proxy-resources.md) 与 [有序路径验收](ordered-paths.md) 保留其原源码、范围和结果，本记录不会将旧结果套用于此次新增源码。真实三设备混合路径仍需冻结签名 Agent 与运行时，核对引用冲突、依赖撤销、共享出口继续承载、故障／重启恢复、入口单次计量和数据库历史／幂等保持；本地数据库及浏览器夹具不能替代该验机，也不代表生产迁移、正式发布或部署。
