# ADR 0080：sing-box 运维预览、用户诊断与客户端工作流

状态：已实施，集中验证发现的失败已修复并通过受影响补验；最终结果见 [本轮验收记录](../acceptance/operations-platform-expansion.md)。生产发布及真实设备签收分别记录。

## 问题与决定

现有插件已负责运行时安装、普通节点、版本化有序链路、来源采用、代理用户、套餐快照、订阅、流量账本与 Passkey 自助入口。直接分配操作缺少逐项影响预览；延期、套餐替换和额度重置容易混淆；管理员也需要知道权限来自哪一处、连接凭据何时真正撤销。

新工作流物理位于 `plugins/singbox/panel/operations_workflows/`，在既有插件路由内部注册。平台 core 不添加代理用户、套餐、订阅或流量业务。前端复用服务器运行时运维和代理用户入口。

策略组批量分配、套餐替换、有效期延长、额度重置、受管节点连接凭据轮换、普通节点迁移和明确备选链路切换，统一采用“固定对象 → 事务预览 → 影响确认 → 状态重新核对 → 幂等应用”。预览与管理员绑定，十分钟过期；确认时重新计算指纹，使用原有授权拓扑锁和对象锁，不采用客户端提交的旧结果。相同预览重复确认返回原收据。高风险确认接入平台五分钟会话再验证，不允许 API 令牌代替管理员会话。

## 数据语义

- 更换套餐：创建新的不可变分配快照，从确认时起重新计算有效期，按照新重置规则归集原账本。
- 延长有效期：复制原套餐快照及原生效时间，仅在原到期日上增加天数；不自动从今天重新开始，不清空用量。
- 重置月度额度：在明确的当前账期保存补偿记录，额度计算扣除补偿；账本原值、设备 epoch 和重放去重键保留。以后到达的旧批次仍按原计量窗口归集，不从历史数据库删除流量。
- 节点凭据轮换：重新生成用户在所选受管节点的连接身份，保留 `stat_name` 账本身份与订阅地址。将每个服务器的原版本、节点集合和新凭据摘要保存为轮换记录；只有在线、最近设备观测、无待发布变化、健康的已应用新版本确实含该摘要，并在设备支持 checkpoint 时取得当前绑定五分钟内的实际核对，诊断才确认。后续轮换替代旧记录，历史确认过期单独显示；现存连接是否断开不据此推断。
- 订阅地址重置：仅替换下载令牌；已下载的节点连接凭据继续由独立轮换处理。外部提供方凭据不能由移除订阅授权伪称撤销。
- 节点迁移：复用独立候选节点及其密钥，不复制 Agent 身份。迁移策略组和直接授权、保留旧节点及历史账本，发布两端目标后等待实际设备确认。链路节点必须走既有候选代数、探测、切换、屏障、恢复和清理流程。

新批次保存首次接收时刻；相同去重键与相同 payload 的重放仅增加观察次数，首次接收与账本不变。相同去重键但不同 payload 仍拒绝。旧批次接收时刻保持 null。计量窗口结束到面板接收的间隔只是一项带时钟偏差限制的证据。

## 运行时边界

当前编译器、路径快照、运行时签名和 Agent 清单仅支持 sing-box 1.14.2。运行时库存复用本地发布签名及每份真实载荷校验，逐版本显示兼容结论、平台、摘要和官方来源；界面明确选择真实库存版本。其他版本拒绝的依据包括 0044 对链路运行时依赖/事实的数据库 CHECK、固定 Agent 清单、探测计划和原生验收版本，不把任意已签名制品导入当成协议或计量兼容。

分批发布冻结逐服务器制品与目标集合，先一台，再按固定批次继续；已选择的制品和后续设备平台冲突时拒绝替换。普通节点的显式候选也创建新配置绑定、保存对应运行时事实，并在该配置版本内保持制品不变。上一批需目标/应用版本一致、健康、待发布清空、本次实际运维读取和五分钟内实际配置/签名执行文件 checkpoint，才能分发下一批。暂停只阻止后续分发；重新读取不会重放部署动作。未完成发布继续互斥，全部目标确认后才释放计划。

普通节点完整部署预检固定当前业务与有效授权、平台、能力、策略、登记入口、关联证书版本和制品指纹。面板实际解析 DNS 并逐族核对全部返回地址与设备/显式 NAT 入口，校验手工证书材料；自动签发须真实编译提供方及节点引用、DNS、挑战端口、制品、目录与系统服务权限同时满足，已签发及部署后握手分别保留真实未知状态。通用 Ports 与 RuntimePermissions 请求采集目标目录、特权执行账号、实际服务后端连接及监听。所有项明确采样时间/来源/证据，未知、失败、截断、过期的阻塞项不能确认；特权 UID 0 与实际连接的后端才可确认服务管理授权，非 root 外部授权保持未知。已有端口仅实际受管 unit MainPID 与当前 checkpoint 同时匹配时允许；不得猜进程名。确认绑定当前指纹与五分钟时效并再次验证，新候选批次实际分发前复核。普通 publisher 对有效普通监听新增或部署形状变化同样要求该确认；未满足则保留目标 dirty，不创建新部署。既有监听内凭据变更、授权撤销、停用及删除不因门禁阻断，链路候选保持原条件。确认触发正常发布再次核对主体当前授权、指纹和时效；实际 Agent 应用回执及部署后的公网/TLS 验收独立。迁移 0055 仅保存脱敏快照与请求编号，按单调序列选择最新记录并按审计策略清理。节点差异隐藏密钥但仍显示凭据变化与受影响用户。

主动核对复用通用 runtime-control checkpoint：Agent 核对配置清单、逐文件字节、符号链接、受管进程执行/配置路径及签名运行时。仅当前绑定且收到 verified 回执才标为核对时一致；确定文件或进程不匹配显示偏差，其他失败保持未知，五分钟后证据过期。目标包摘要不冒充单个实际文件摘要，`revision_aligned` 仍只表示版本回报一致。

备选切换要求显式选定原链路、备选链路及策略组，确认备选已通过现有路径资格判断。旧路径保留；不建立自动出口池，不创建绕链直连回退。

## 客户端与隐私

客户端模板固定 sing-box 1.14.2 完整 JSON 模型，仅表达选择组、受限 DNS 和路由字段。未知字段、组成员丢失、出站引用不一致均明确拒绝，不过滤参数、不回退到直连。模板在完整 JSON 订阅中应用；链接订阅遇到模板时拒绝并说明须使用完整 JSON。服务器侧配置和凭据不受模板影响。生成及模板引用检查不能替代目标客户端的真实配置检查。

诊断整合账号、套餐、授权来源、部署、外部来源状态、订阅生成、批次、补偿、历史套餐与轮换确认。用户限速、连接数限制及外部凭据撤销在当前能力不足时明确不可用。自助入口通过既有独立用户会话显示自己的用量、到期、额度和具体不可用原因。

审计记录主体、对象、影响、结果和时间；不保存订阅令牌、连接凭据或原始客户端 IP。管理员动作、订阅生成/阻止、独立 Passkey 登录/失败/退出/邀请/密钥增删分别记录，保留天数取插件分类策略与平台 audit/proxy-access 策略较短值；订阅获取 0 天表示停记。后台三十秒清理不删除原计量账本、套餐历史、轮换或部署证据。发布周期真实阶段结果写入系统心跳，清理失败保留到重试成功，不因其余步骤通过而隐藏。外部 API/实机操作不作为开发测试默认动作。

普通用户与授权读取在无 `proxy:write`、API 令牌或管理员证明过期时隐藏订阅令牌/地址和连接 UUID。完整订阅及模板敏感字段的专用读取要求五分钟内交互式证明；旧订阅弹窗复用平台再次验证重试。模板脱敏视图不能直接保存，受控揭示保留原修订号；密钥写操作也接入平台高风险守卫。诊断不携带订阅令牌；实际凭据读取只审计对象编号、入口、数量、格式等元数据。

## 验收

新增单元用例覆盖凭据变化脱敏、模板不丢字段、未知字段与失效引用拒绝、不同操作不可混用；数据库用例覆盖补偿后迟到用量、延期快照和预览因用量/策略改变失效。用例已纳入集中执行，失败修复后的受影响补验通过；工作区汇总按目标替换复验结果，避免重复累加。具体模块逐项覆盖、已知验证结果与实机边界见 [sing-box 运维流程](../singbox-operations-workflows.md)。
