# ADR 0079：DNS、证书与受管服务器网络配置

状态：源码实现；集中验证及受影响补验已执行，真实提供方与目标设备验收尚未进行。

## 背景与边界

2026-10-03 用户授权清单第三部分要求 DNS/DDNS、域名证书、NAT/反向隧道/私有组网与系统网络调优。授权覆盖旧 MVP 排除项，仍保留插件分层、受限 Agent 能力、特权与服务管理 trait、签名制品和真实操作验收边界。

DNS 官方 API 与秘密继续位于 `plugins/ddns/panel/`，不转交 Agent。服务器网络配置与证书台账位于面板独立 `network_configuration` 模块；系统执行经过共用 fleet 队列、双侧默认关闭的能力授权、`Privileged` 和 `ServiceManager`。每台服务器的操作串行，维护与退役限制由共用队列实施。用户异步请求保存管理员主体，派发前重新核对功能及服务器权限；当前 API 令牌不允许排队，避免令牌过期、撤销与限权被转换成普通管理员权限。

## DNS 对账

普通 DNS 账号集中引用加密凭据，明确提供方、允许区域与服务器范围。Cloudflare、阿里云 DNS、腾讯 DNSPod、华为云 DNS 分别使用官方接口。不同线路、记录集合、结构字段、备注与异步受理能力单独表达，不静默舍弃参数。

变更先保存五分钟预览、账号和规则版本、完整远端快照，再用一次性预览执行。写入前重新读取快照；结果未知只允许读取核对，不自动重放。没有返回记录标识的新建，即使观察到相同值，也不能证明归属，不能自动认领后删除。回退必须匹配已确认历史与当前远端值；自动 DDNS 在回退后暂停，避免立刻覆盖人工恢复结果。

DDNS 明确网卡、Agent 地址、公网发现或手工来源。缺少来源、离线、陈旧或凭据失效时保留现有解析，不回退到别的来源。A 与 AAAA 事务创建但各自对账。面板向选定解析器发起真正 UDP 查询，在截断时向同一解析器回退 TCP，保存问题、返回码、TTL、耗时与期望集合。提供方已接受与解析器已观察到分别保存。

## DNS-01 签发、私钥与部署

由维护方明确选择面板为执行者，使用签名制品库存里的固定版官方 lego；拒绝 `latest`、未验签二进制、缺平台制品、未接受 MIT 许可或签发服务条款。初始适配 Cloudflare 和 Let's Encrypt 生产/预发布服务，支持普通域名及适用的通配符；其他签发服务与 DNS 提供方没有隐式替代。lego 执行 ACME 协议与密码学，不自行实现 ACME 签名。

每项签发固定证书及域名版本和申请管理员。后台执行前复验权限、配置与凭据；工具环境只含必要 DNS 密钥，标准输入/输出/错误不进入普通日志。独立 0700 工作区含有界账户及结果文件，完成后清理；账户材料与私钥进入凭据中心 AES-256-GCM，公开证书链与有效期保存为历史版本。签发、保存、选择期望版本、部署、实际握手保持独立状态。中断或超时转未知，要求远端核对与 TXT 清理，不自动重复下单。

证书批量部署使用一次性固定目标预览，明确服务器、服务、证书路径、私钥路径和接管现有文件授权。队列仅含部署标识；只有对应 Agent 的有效派发身份接口在内存返回材料，并设置 `Cache-Control: no-store`。Agent 检查证书与私钥匹配、目录与服务授权交集、受保护路径、普通文件及父目录权限，写入后重载受管服务。私钥按真实服务组设置 0600/0640；失败恢复旧内容、属主与权限后重载，不能确认恢复则明确失败。历史公钥指纹和服务状态可通过独立只读接口核对，既不读取私钥也不重放部署。

新增 `tokio-rustls` 与 `webpki-roots` 仅用于原生 TLS 验证。复用已使用的 rustls/ring，而非通过 HTTPS HEAD 验证证书，因为部署服务可以是非 HTTP 的 TLS 服务。面板固定解析后的公共地址建立有界 TCP/TLS 连接，核对系统信任根、域名与期望叶证书指纹；预发布证书正常显示信任失败。该观测不推断其他来源或未来时段的可达性。

## 网络执行与失联恢复

端点区分监听与公开地址、端口、协议和受管/外部责任方。受管转发由 Linux systemd 和现有 socat 执行，分别支持 TCP/UDP 及 IPv4/IPv6；先核对受管配置的通配监听重叠，并读取实际 `ss` 监听。服务运行不代表外部可达。初始转发为临时服务，结束或重启后需核对，不隐式安装工具。

反向隧道复用 OpenSSH，使用独立隧道密钥、明确中转账户、固定主机公钥和严格验证，只发布声明的 TCP 服务。中转须提前授权独立公钥并配置合适的转发范围；不复用 Agent 身份。私有组网复用 WireGuard，密钥保留本机，只允许明确的私有 CIDR 和成员，禁止默认路由；配置、实际握手与业务探测分别显示，应用失败恢复前一受管文件及原接口状态。

调优先读实际 sysctl 与算法能力。只允许有界参数；临时应用前必须成功安排独立 systemd 恢复计时器，恢复脚本不依赖面板连接。确认结果后解除计时器，再单独持久化；持久化合并已有受管参数，并保存原文件。回退前核对目标文件仍是本次结果，拒绝覆盖外部修改。

防火墙仅管理每项配置自己的 nftables `inet` 入站表，不修改外部表。保留回环、已建立连接及明确管理端口；预先用 `nft -c` 检查，先安排本机恢复计时器，再应用事务。确认与持久化分开；外部表、路由或硬件故障仍可导致失联，不能承诺恢复覆盖所有情况。

## 交付与限制

服务器替换必须是独立的固定对象迁移流程，不能由普通配置编辑替代。0056 保存原发起管理员、源/目标、所选业务、原期望摘要、版本与关系、目标能力/范围、证书版本、凭据引用元数据和五分钟预览。确认重新核对权限并在锁定事务中重建摘要；目标冲突、身份变化、凭据停用或待确认执行均阻断。仅普通业务服务器引用改变，原Agent身份保持独立；WireGuard/SSH以新业务UUID创建候选、保留源对象，并在目标本机重新生成密钥，不迁移独立身份。配置保存、受管部署、实际握手与源服务清理分别记录，历史不因替换而覆盖。

界面提供配置草稿、并发版本冲突、明确预览、逐台回执、历史和配置关系图。关系箭头表示配置，未观测时仍显示未验证。资料有执行、观测或证书历史时保留台账，不能通过删除抹去历史或留下受管服务。

执行器依赖目标已安装的 Linux 工具、独立授权与签名 lego 库存。集中软件验证已执行，DDNS、网络配置与迁移的数据库/API 用例以及前端用例已通过；Huawei DDNS 更新请求回写旧描述的修复也已通过补验。完整检查、测试、失败修复和条件跳过结果见[本轮验收记录](../acceptance/operations-platform-expansion.md)。真实 DNS 写入、ACME 签发/续期、证书部署、转发、WireGuard、nftables 和失联恢复尚未实际操作，软件用例通过不等于外部或目标设备签收。工具许可证、安装路径、逐项覆盖与验收条件见[网络配置使用与验收](../network-configuration.md)。
