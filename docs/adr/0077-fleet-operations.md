# ADR 0077：服务器生命周期与独立日常运维能力

状态：2026-10-03 用户授权的源码实现及集中回归通过；真实设备能力按验收记录分别签收。

用户一次授权清单 1–3，覆盖旧 MVP 对终端、受限文件操作和权限的排除。保留 Agent 主动连接、特权与服务管理 trait、插件业务边界和设备独立身份。

服务器台账、接入模板、逐台批量登记、采购配置与观测配置并列、货币原值费用账本、维护窗口、停止接收任务、能力列表属于面板 fleet 模块。模板中的拨测与告警都生成独立标识，每台接入凭据独立且有期限。采集配置迁移只复制采集设置并重建拨测标识，目标设备公钥、会话、接入凭据与计量不复制；业务迁移由相应插件助手显式确认。

日常操作使用独立强类型 fleet 协议与持久队列。任意命令仍保留原来的提交、领取和结果机制，不把它改称终端。操作在分发前固定参数与授权快照，派发时重新校验管理员范围并与当前设备 policy 取交集，只交付一次；响应丢失后由 Agent 结果 outbox 重送，结果摘要不可修改。已交付操作超时属于未知结果，不能自动再次执行。独立未知核对派发关联的强类型只读观测，近期成功 Agent 证据及再次认证后才允许人工记录失败/未知结论与执行停止、清理确认；manual reconciliation 独立保存，迟到的真实回执保留且不伪造 Agent 成功。自动化在同一事务绑定步骤与 fleet 操作，通过原作业锁识别自己；普通新任务不能绕过互斥锁。Agent 共同执行锁串行处理日常操作，拿到锁后重新核对本机授权、期限和退役状态。

交互式终端使用 Linux systemd 瞬态服务中的 Python 标准库 PTY：真实系统账号、实时输入输出、窗口尺寸、Ctrl+C、空闲和总时限。Python 是此平台已有可选工具，不加入 Rust 依赖或 unsafe 代码。systemd 管理 cgroup，关闭时核对停止状态与空控制组；断线仍有本机时限，重启不恢复原会话。支持条件必须如实显示，OpenRC、macOS、FreeBSD、Windows 未实现此 PTY 后端。

面板授权与 Agent 本机 0600 的 `fleet-policy.json` 取交集。设备默认不开终端、服务变更和文件访问。终端创建需要管理员近期再次认证，绑定管理员会话；会话失效、权限撤销、账号撤销、维护和退役均请求关闭。每个输入和输出带序号，取消请求与停止确认分开。日志与输出有界，普通操作历史不暴露受管文件内容。

受管文件走 Privileged trait。Linux 文件 helper 使用逐级目录 fd 与 O_NOFOLLOW，不跟随软链接，不访问设备、procfs、sysfs、设备身份和敏感文件，拒绝硬链接与非普通文件。既有配置文件保存前核对旧 SHA-256、新内容完整性和 JSON/TOML 语法；二进制上传使用独立 FileUpload，不强制 UTF-8。明确新建只接受缺少旧 hash 的目标，排他创建最终目录项并用 0600 权限；既有目标必须核对旧 hash。同目录写临时文件、fsync、检查文件身份后原子替换，写路径的祖先目录不能由其他账号写入。保存与服务应用分开，后者经 ServiceManager。证书部署使用独立 UUID 任务，私钥仅执行时从受控材料接口取得，不写入通用文件任务队列；部署仍核对本机与面板目录/服务授权、配置中实际的身份保护路径。systemd 的 User/Group 是系统执行账号属性，用于从真实服务配置确定证书私钥读权限；边界检查只放行该属性串与精确属性读取表达式，不豁免文件或整行，也不允许代理账号模型进入 core。此版本上限 256 KiB，不提供大文件续传、任意目录浏览或未检查的二进制上传。

监控保持原时间戳与缺失状态。Agent 额外采集进程、控制组、CPU steal、I/O wait、PSI、交换空间和 OOM 累计信息。进程清单最多 64 项，服务汇总在进程展示截断前计算全部已观测进程；分组最多128项、扩展总预算64KiB，超限明确截断且不产生假退出事件；不将容器或不支持指标伪造为零。重启、OOM、磁盘只读状态变化和服务进程组消失来自真实采样，迟到样本不反向改写事件。网卡分类展示虚拟与物理关联及重复风险，统计仍使用显式已有匹配规则，不能由地理或设备名称推断完整网络拓扑。

本轮实现期间未运行测试、构建、格式化或静态检查；整合冻结后统一执行。协议拒绝任意 shell 与只读操作多余字段、授权交集、路径逃逸、身份保护、真实注册服务单元及未知账号不继承 root 权限的回归已经通过。实际 Linux-root/NSS 降权后拒绝 root-only 证书目录的隔离用例通过，属于一项独立方法，不将默认忽略用例改记成整套设备验收。最终源码与制品身份、完整验证范围见[平台集中验收](../acceptance/operations-platform-expansion.md)。Linux systemd PTY、完整传输和服务控制仍需要独立设备验收。

运行时只读权限预检使用已注册适配器的 Descriptor：模块目录来自受限的 `plugin_name`，实际服务单元来自 `service_unit`，不由面板传入模块名猜测 systemd 单元。系统服务管理器只读取得实际已安装单元的 LoadState、MainPID、User、Group 与 SupplementaryGroups；只有已加载单元中真正观察到的空 User 字段，才能按 systemd 的明确语义解释为 root。单元未安装、属性缺失、账号解析失败都保持未知，不把 Agent 的 root 身份补成运行时账号。

目录 helper 先以特权身份通过逐级目录描述符核对 root 的安装条件，关闭这些描述符后，解析实际运行账号的 UID、GID 和补充组并在独立 Python 进程中降权，重新从根目录逐级检查实际读取、写入和遍历权限。运行时根目录需要服务账号能读取和遍历；自动证书数据与证书目录还需其实际写入权限。0700 的 root 证书目录不会因 Agent 可写而通过业务部署预检。只读探测不创建账号、目录或测试文件；首次账号尚未存在时，插件的明确空运行时安装流程与业务配置部署预检分别处理。User 原生属性串与精确读取表达式只有所在调用文件的窄边界例外，相邻代理业务字段仍被拒绝。
