# ADR 0066：诊断结束也等待设备清理确认

> 主线整合编号 0066；作者原独立分支编号 0049。旧主线同号决策及链接保留，历史验收仅认证原冻结输入。

状态：已实现，原冻结输入的统一验收结果见[专项记录](../acceptance/confirmed-diagnostic-completion.md)。本轮非空目标补修及当前集成结果见[生命周期整合记录](../acceptance/lifecycle-issues-integration-2026-10-03.md)和[总交付记录](../acceptance/all-open-issues-20261003.md)。本次不解除完整验机许可和制品门禁。

## 问题

原自然结束路径先原子清空活动记录、写入终态，再尝试停止诊断单元。最后停止失败只记录警告；下次任务可以进入准备，Agent 重启也失去待清理目标。低内存路径虽然保留停止原因，却只检查服务活动状态，没有取消路径已有的控制组和挂载证据。期限停止原因没有持久化。Agent 退役也接受非 Running 状态，未取得同等清理证明就继续清除凭据。

## 决定

沿用 Started 检查点，增加可缺省的 `terminal_update` 和 `cleanup_error`。旧检查点仍可读取。自然成功、失败和丢失单元先采集有界报告并保存原始执行结果，再清理；停止后 systemd 返回 Missing 不改写先前成功或失败。已经固定的结果在重启后只重试清理，不再次执行、重新采集或因适配器移除丢失报告；已经固定为无整体报告的结果在取消接管时也不重新采集。

低内存、内存状态不可读和两种期限先持久保存停止原因，立即停止受控单元，再保存最终报告。状态查询挂起时也定时检查内存和期限。持久化失败不能阻止保护停止，但仍保留原活动记录，不能假装原因已经落盘或结束已确认。准备阶段发生错误时，已写入 Started 的任务继续由观察流程持有，不能退回一般准备失败并释放占用。

自动结束、管理员取消和退役复用相同的停止与证据接口：停止请求、cgroup 子树、主进程/控制进程、私有挂载和工作目录挂载检查，以及最后没有排队或活动 job。状态查询未知不能跳过停止；受控查询预算结束后仍尝试停止已绑定单元。任一证据失败、超时或仍有残留，保留活动记录并重试。服务后端不支持证据时，启动预检拒绝；已有 Started 的后端能力变化仍尝试停止，但证据未知就不能提交完成。其他历史 UUID 的待取消意图不能阻塞当前活动任务的内存/期限保护，保留请求并在当前所有者清理之后处理。退役在清除凭据前再次核实，清理不成立时保留身份及诊断证据。

所有观察、状态通知、取消及退役在特权调用前校验非空 UUID、生成的单元名、配置中的工作目录、程序与安装根及超时的一致性。不能从损坏的检查点转去停止其他服务。活动检查点更新与终态提交在同一 SQLite 锁下核对当前任务、不可变结果和 done 账本；取消请求已消费并确认后，晚到观察也不能复活任务或另写自然终态。取消接管并清掉原所有者时，连接监控丢弃被挂起的旧观察协程。已到达的取消意图在终态事务内核对，不能被自然结果提前释放。

## 面板与协议

新增 `cleaning` 为非终态，`is_terminal()` 只接受 succeeded/failed。设备宣告 `diagnostic:confirmed-completion` 表示采用本收尾流程，原取消能力仍表示相同服务证据可用。面板和前端同版交付；旧面板不认识新状态，不能把新 Agent 单独部署到旧面板。

面板保存等待原因和可读报告，不置 `agent_completed`；清理待确认不因期限过去而释放同机互斥。旧 Running 消息不覆盖 cleaning。已有取消请求继续等取消确认，Cleaning 不能充当取消完成。真正终态仍幂等，报告与独立章节继续可读。

晚到 cleaning 与新任务创建采用相同服务器行锁。若旧任务已被面板超时标失败且另一任务已取得占用，保存晚到报告和原因、返回 409，旧记录暂保留 failed / agent_completed=false；下一次可在占用释放后恢复 cleaning。设备自己的活动记录始终阻止第二任务执行。断连时面板可能暂时看不到最新清理阶段，超时标记不等于设备已清理。

迁移只增加诊断状态及活动唯一索引，不改代理业务表名、旧订阅、历史任务/报告/章节。保留既有取消状态的准入策略，不用本迁移推断历史同机取消关系。

## 验收边界

本步骤验证原始结果保留、资源停止、失败/超时/重启恢复、目标隔离、取消/退役、面板事务互斥和实际构建页面。专用 Debian 12 上的当前 Rust/systemd 实现，以及持续 Agent/代理业务与完整 NodeQuality 联合负载，必须另有实机证据；Mock、旧二进制、普通构建容器和 UI 夹具不替代这些验收。
