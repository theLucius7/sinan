# ADR 0067：周期拨测来源与可撤销执行许可

> 主线整合编号 0067；作者原独立分支编号 0050。旧主线同号决策及链接保留，历史验收仅认证原冻结输入。

状态：集中实现与本地统一验收完成，实机效果另行签收。

## 问题与范围

三网周期监控要求目标可配置，使用第三方节点前先取得同意。原有 `ProbeSpec` 只有线路备注；Agent 将配置与本机抓取时间保留一天，断连或 GET 被拒绝仍继续采样。重新分配的新 UUID 和目标不可变规则已经正确，但面板丢弃迟到结果不证明设备停止。旧会话的在途响应也可能覆盖新连接的配置。

本步统一修改 core 周期拨测的协议、面板、Agent、三个管理入口、测试代码和操作说明。修改期间不运行测试/构建；全步完成后冻结并统一验收、提交。独立 IPQuality 制品、完整硬件测试、代理链路业务和生产发布不由周期拨测许可替代。

## 目标与使用依据

`ProbeSpec` 的原八字段保持。管理员输入和存储另加 `ProbeAuthorization`：地区、目标来源、自有目标/第三方已获同意、管理或同意记录、可选截止时间。地区未知可空，来源与依据不能为空；有 UTF-8 字节及控制字符限制。第三方依据是管理员明确记录的同意，不自动联系对方、猜测所有权或从运营商名称推断许可。

旧目标及历史不删除、不重写测量身份；缺授权记录或已到期目标不下发。启用的创建/修改必须具有有效依据，旧目标可先暂停，再补依据。统一任务授权连同分配在同一事务修改；默认任务在缺依据/到期时不自动作用于新服务器。单机与统一任务编辑、删除使用读取到的修订号，避免过时表单覆盖或删除其他修改。前端读失败或刷新未完成时保留草稿、拒绝写回，真正提交回调再次核对。

`network_probes`、`latency_tasks` 表名及原 spec 保持。新迁移独立增加授权、单机修订号和服务器拨测配置修订号，未知旧数据不凭迁移赋予同意。配置/分配/启停/依据改变提升服务器配置修订；到期导致有效目标集合改变也提升修订，每个修订对应固定授权定义集。

管理员可查看依据。匿名看板只收到安全的授权状态，来源/同意记录及执行证明不进入公开结果。未知保持待确认，到期保持到期；不把旧 enabled 标记当作仍获准执行。

## 下发与设备执行

新能力为 `probe:authorized-lease`，新接口为 `/api/agent/v1/probe-lease`。旧 `/api/agent/v1/probes` 仍返回八字段数组，只筛有效授权目标。旧设备不能因面板升级获得新停止保证，需要同版升级并核实。

租约绑定实际设备、随机 ID、持久单调配置版本、面板签发/截止时间和最多 32 个明确授权目标。期限最多 90 秒，并受任何目标的许可截止约束。面板保存签发时间及各目标定义摘要；同版本/同有效目标的短窗口重复领取仅复用原 ID 和期限，不重新起算。收据只保三小时、每服务器最多 512 条，以覆盖当前 Agent 两小时补传窗；该上限不延长执行许可。

Agent 启动不从旧持久配置恢复权限。只能接受当前连接实例的成功新租约；错误设备、重复/非法目标、过期、配置回退、同版内容改变或签发时间倒退均拒绝。高水位持久化成功才开放执行，重开 SQLite 继续拒绝回退。GET/上传分别最多五秒，连接变化优先取消旧请求；旧响应不能恢复权限。

同会话保存最多 64 个仍可合法重复领取的收据；A、B、A 交替不会忘记 A 的原字节或单调期限。相同身份不可改写，期限只能缩短。经高水位确认的新签发时间超过旧收据绝对期限后才释放旧收据；容量不足则拒绝新许可并撤销执行。GET 失败保留收据约束，会话换代清空权限和收据。本轮补修、最终本地结果与准确实机边界见[生命周期整合记录](../acceptance/lifecycle-issues-integration-2026-10-03.md)，工作区与相关许可合同验证纳入[总集成交付](../acceptance/all-open-issues-20261003.md)。

收到许可时扣除请求耗时，将剩余期限映射到单调时钟。主机墙钟回拨不延长正在执行的期限；重启重新取得许可。失联、换连接、刷新失败、空集合、目标/依据改变或到期都取消在途工作，完成结果再次核对当前所有权。测量具有独立运行 ID，旧任务的完成/取消不能移除同目标新任务。相同定义的续租不延长一次测量原始许可的截止。

保留原每轮四次、最多四路和 12 秒单轮上限。最多 32 条采样周期先持久化再执行，重启及名称/备注变化不会形成额外突发；间隔调整从已开始时间计算。无法持久化或周期时钟无法解释时不发出测量，不能通过重启绕过周期。TCP future 取消关闭自有连接，ICMP 委托既有有界执行和所属进程组回收；实机过程效果需要对应验收。

## 结果与边界

新结果另带签发 ID、版本、签发/截止及完整授权目标上下文，旧结果缺 execution 仍兼容原 JSON 字节和重复 digest；新历史必须带 execution；新能力设备升级补传的无证明旧记录确认丢弃，不阻塞同批有效结果，已保存的精确重复仍可确认。时间以收到租约时的期限与单调经过时间映射，是受网络耗时影响的估算时间，不声称与远端测量时钟精确一致。面板核对真正签发的目标摘要和窗口；当前目标/授权撤销或上下文不一致的迟到新结果确认丢弃，不变成新的成功历史。已保存的重复内容继续幂等确认。

删除/暂停保存成功表示面板定义已变更；设备未同步之前仍可能在原短期限内执行。界面不把写成功当成设备停止确认。收到断连和刷新失败可主动停止，未观察到变化时依靠单调截止；旧设备仍保留原离线缓存限制。真实 Agent 心跳、标准 ICMP 权限、跨平台工具、专用节点重启/断网及持续代理负载需独立证明，不由 HTTP/进程树夹具推导。
