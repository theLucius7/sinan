# ADR 0082：管理员授权、凭据中心与操作上下文

## 决策

用户本轮明确授权多管理员、按功能和服务器授权、凭据中心、API 令牌和全局操作效率，覆盖旧 MVP 排除项。保留初始管理员编号 1 和旧密码/TOTP/Passkey 登录，新增具名管理员密码/TOTP 登录。代理用户继续由 sing-box 插件独立维护。

面板路由统一执行能力和服务器范围检查，未分类接口对非所有者拒绝访问；设备、公开看板、订阅及代理门户沿用各自身份检查。只读角色不可写；受限服务器授权不隐式允许跨服务器聚合、密钥和全局设置读取。高风险操作要求会话绑定的五分钟再次验证，API 令牌无法提供该证明。令牌仅保存摘要、有效期、能力与服务器范围，权限与当前管理员权限取交集。

凭据使用 AES-256-GCM，随机 nonce，身份、用途及版本作为认证附加数据；独立运行时密钥环不落入数据库或普通日志。直接声明已有传递依赖 `ring = 0.17.14`：它提供经维护的认证加密实现；现有 SHA/HMAC 仅可摘要或认证，不可安全替代加密，自制算法和明文存储均不采用。主密钥通过 SINAN_CREDENTIAL_KEYS / SINAN_CREDENTIAL_CURRENT_KEY 配置，缺失时拒绝凭据写入和解密。旧密钥保留直至轮换完成，恢复材料须包含独立密钥位置。

全局搜索只返回授权范围内的可跳转实体；收藏、最近访问、视图及草稿按实际管理员隔离，使用版本号检测并发修改。审计只留有界脱敏请求、主体、对象、结果，不保存口令、令牌、私钥、终端输入或文件正文。各种记录分别配置保留期限；未知健康状态不报告正常。

## 验收边界

实现阶段按用户要求不测试、不构建、不验证。所有模块整合后统一验证；实机终端、云资源、DNS 写入、独立观察点及 NodeQuality 完整执行分别保留原授权和许可门禁。

## 交付运行镜像的备份依赖

定时完整备份需要与现有 PostgreSQL 16 兼容的 `pg_dump`。运行镜像从官方 `postgres:16-bookworm` 构建阶段复制客户端和匹配 libpq，Debian 安装其既有动态依赖及 `age`，不在面板容器中启动数据库服务器。备份清单保存实测客户端版本、服务端版本、数据库迁移身份、面板版本与内容摘要；不以容器标签代替工具版本证据。`age` 负责面向独立接收者公钥的备份加密，私钥不进入面板工作区。本轮已实际核对pg_dump16.15、age1.1.1和动态库，最终原生面板配对的隔离备份/恢复结果见[集中验收](../acceptance/operations-platform-expansion.md)；开发兼容镜像不能替代完整生产Docker构建与发布验收。

## 工具与依赖风险来源

编译期复用工作区既有 toml 0.8 及 serde_json 读取 Cargo.lock，生成当前精确依赖版本清单；生产面板不依赖 Cargo 命令或扫描宿主全局包。构建脚本跟踪迁移目录及锁文件变化，避免稳定编译器下迁移宏缓存未刷新。管理员可显式查询 OSV 官方 API 的精确包版本建议；网络错误、未支持的生态和缺失资料保持未知，固定修复版本只是来源建议，不替代兼容性与签名制品预检，也不自动升级。
