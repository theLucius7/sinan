# 全局搜索与对象可见性

`GET /api/control-center/search?q=...` 先核对当前管理员与 API 令牌的能力、服务器范围交集，再在每类查询中筛选可见对象，最后取最多20条。额外一条只用于判断截断，不返回给用户；响应包含各类别的数量、上限和实际 `truncated`，数据库错误返回失败，不转换为空列表。

搜索读取真实服务器名称和三类 StaticInfo 地址：网卡地址、按网卡保存的地址、公网出口发现地址。同一服务器相同地址合并显示来源。IP 来源观测、IP质量资料、DNS记录、域名证书、网络规则、诊断及综合测试、远程命令、设备操作、运维任务计划、自动处置、维护窗口、事件和监测规则各自按已有功能能力授权。结果保存具体对象编号及现有工作台或服务器上下文路径，不构造不存在的详情页面。

多服务器对象必须全部关联范围可见。网络台账包括引用域名、转发依赖及 DNS 规则；综合测试包括冻结步骤与执行清单的来源、接收端、反向端，关联计划定义和历史实际结果服务器；运维任务及其故障事件包括所有固定目标。操作细项仍需要对应文件、服务或网络权限。

服务器范围为空不自动代表全局管理权限。它按所属接口的真实规则解释：

| 对象 | 搜索与详情读取要求 |
|---|---|
| 仅从面板执行、没有受管服务器关联的综合测试方案及报告 | `diagnostics:read`；与网络工作台 `authorize` 一致，不要求 `global_servers` |
| 没有关联服务器、域名或 DNS 规则服务器的网络台账 | `network:read`；与网络配置 `documents::access` 一致，不要求 `global_servers` |
| 代理节点、代理用户，以及旧全局告警规则和延迟任务入口 | 对应读取能力及 `global_servers`；不能通过空数组得到全局页面的标签 |
| 无服务器关联的 IP 观测、平台故障事件 | 仍要求对应读取能力及 `global_servers` |

有对应功能读取能力的受限管理员可以读取前两类共享功能对象，只有面板来源不意味着可以读取其他服务器记录。方案增加接收或反向服务器、台账新增服务器或引用后，搜索会重新按完整关联集合过滤。只读共享对象也不授予修改、执行或高风险操作权限。

`sampled_at` 只用于真实观测，监控与探测注明毫秒，IP及网络观测注明秒。StaticInfo 使用 `received_at`，DNS提供方接受更新使用 `last_success_at`，对象修改使用 `updated_at`；这些时间不冒充采样时间。响应生成时间单独保存为 `served_at`。搜索不读取或返回订阅凭据、私钥、命令及文件正文、原始报告正文或通用秘密配置。

对应独立 SQLx 测试源码位于 `crates/panel/tests/control_center_search.rs`；本轮集中执行7项全部通过，覆盖真实数据库范围过滤、截断与错误语义。源码身份及完整验收边界见[本轮记录](acceptance/operations-platform-expansion.md)。
