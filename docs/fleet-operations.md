# 服务器日常运维

本页对应新授权清单 1–3。源码能力与设备验收分别记录；本轮实现期间没有运行验证、测试或构建。

## 接入、资产与生命周期

服务器运维页可保存接入模板，包含默认分组、标签、拨测、资源告警、采样与持久化间隔、采购资料。批量登记限制 100 台，各台使用单独事务，响应逐台显示登记成功或失败，并仅在当前响应给出各自独立、一次性、24 小时有效凭据。登记成功不代表 Agent 已接入，服务器原接入页继续生成保留 GitHub 来源与验签的安装说明。

资产保存供应商、云账号参考、地区、订单参考、购买配置和备注。购买 CPU、内存、磁盘与实际采样并列；未观测带宽保持未知。能力清单显示设备真实上报的采集、诊断、运行时、取消、文件与 PTY 能力。费用以最小货币单位和原币种记账，续费、购买、退款、价格变化和退订独立保存；年度汇总按币种分开，价格变化不会重复计为支付。提供 valid_until 的续费记录更新到期日期，继续复用现有到期告警。退订记录的 valid_until 明确表示计划退订生效日期，采购/续费的同字段表示新的到期日期；退订记录不会修改服务到期或自动停服。专用退订通知通过 `/api/operations/cancellation-reminders` 保存 `{record_id,enabled,lead_secs}`：默认未启用，提前 1 小时至 30 天（默认 7 天），每条记录创建唯一站内事件并沿用通知 outbox 的维护抑制与重试。notified_at 表示事件创建，实际通知投递状态单独保存；配置与触发均重新检查管理员当前范围。

维护窗口保留采样与告警证据，但在窗口内停止通知投递和新命令、诊断、运行时运维分发。typed 日常操作与命令、诊断清理、已交付运行时操作交叉检查；日常操作最多排队 16 项、每次只交付一项，结果未知持续阻止新冲突任务。停止接收任务永久禁接，直到人工恢复；已有操作不冒充已停止。退役继续走现有在线清理回执/离线未确认机制，不能通过修改生命周期直接伪造清理。关联插件与应用状态可在资产页检查。

采集配置迁移先显示来源、目标、拨测、插件与应用关系，再用影响摘要确认；目标已有拨测时拒绝覆盖。只复制采集设置并生成新的拨测 ID；不复制 Agent 公钥、设备会话、接入凭据或任何计量身份。代理节点、授权、订阅及链路使用 sing-box 的独立迁移助手。

## Agent 本机授权

在 `agent.toml` 所在目录创建 `fleet-policy.json`，权限设为 0600。例如允许例示服务与受管配置目录：

```json
{
  "terminal_accounts": ["operator"],
  "services": ["example.service"],
  "read_directories": ["/srv/example/config"],
  "write_directories": ["/srv/example/config"],
  "maximum_file_bytes": 262144,
  "system_network": false,
  "port_forward": false,
  "private_mesh": false,
  "reverse_tunnel": false,
  "firewall": false,
  "certificate_deploy": false
}
```

这是本机管理员明确授权，安装 Agent 不自动启用。面板资产页还需授权相同范围，实际执行取交集。通用文件访问始终禁止设备身份、Agent 配置、本机授权文件、私钥、证书 PEM、SSH、系统口令文件和凭据文件。证书采用独立部署任务：队列只保存部署 ID，执行时从已授权材料接口获取，核对本机/面板证书授权、允许目录和服务交集，私钥不进入操作队列、普通日志或结果。目录只能明确指定，不得授权 `/`。授权文件更改后 worker 每轮重新读取，新增能力列表需要 Agent 重新连接/启动。

## 监控与运维

Agent 进程采样保存 PID、父进程、名称、CPU、内存、读写总量与采样差值、服务/cgroup 和容器标记。按 CPU/内存显示前 64 项，服务/cgroup 汇总在截断前按全部已观测进程计算，最多展示 128 个分组，进程归属扩展总预算 64 KiB；超限分别标明进程/分组截断，缺少分组不当成服务退出。不等同完整容器统计。CPU steal/I/O wait 来自 `/proc/stat` 差值，PSI 来自 `/proc/pressure`；不支持或首个差值缺失保持未知。现有交换空间、磁盘 I/O 和采样时间继续保留。重启/OOM 事件从 boot ID 与内核计数器变化记录；已观测设备从可写变为只读、已观测服务进程组消失会记录对应证据，服务组消失不自动断言服务退出。网络断连复用现有在线状态告警事件。真实 ServiceManager 回执具有运行→停止状态变化或非零退出码时，另外记录 `service_exit_observed`，包含服务、退出状态、操作与观测时间；首次发现inactive且无退出证据时不宣称退出。重复状态去重，已观测再次启动后允许新的退出事件；观测时间不冒充精确退出时间。完整 journal 订阅与全部系统异常仍不在此范围。

网卡页显示每个设备的物理关联、回环和虚拟/未知分类，以及重复计数风险。已有统计匹配可指定网卡或排除模式；空匹配仍使用原行为，不能宣称所有虚拟拓扑已经自动去重。历史 API 支持两段明确时间范围、同指标和不同服务器；缺失值不填零。界面提供最近两天比较，升级前后自定义范围通过 API 可用。

受管服务支持状态、启动、停止、重启，systemd 可开关开机启动。状态含服务结果、退出码、PID 等真实信息，其他后端只声明实际支持内容。监听查询通过 `ss` 提供地址、TCP/UDP、端口和进程；应用归属取已知服务证据，缺少对应工具会失败而不返回成功。

日志复用 ServiceManager 有界近期日志，支持时间、优先级和文本筛选，界面每五秒跟随，可暂停和下载已授权窗口。它不是无限历史日志存储。文件读取返回大小、原始二进制内容与 SHA-256，浏览器核对实际字节数和校验后生成下载。二进制上传单独使用 FileUpload，明确本机/面板目录交集和最大 256 KiB 预算，上传前计算 SHA-256。新文件必须明确选择创建模式、旧校验值为 null；既有文件必须先读取并提供旧 SHA-256 才能替换。新建以同目录受控临时文件和排他链接创建最终目录项，不能覆盖并发创建的文件；新文件默认 0600，父目录必须已经存在。界面分别显示准备、面板请求传输、已排队、已派发待 Agent、成功/失败/未知，不虚构字节百分比。

受管配置编辑与二进制传输分开：JSON/TOML/UTF-8 文本先语法检查、旧值比较，原子保存并保留历史；保存不自动重启服务。目录浏览、大文件、断点续传与完整字节进度没有实现。

独立 PTY 需要 Linux systemd 与 `/usr/bin/python3`，允许的系统账号必须存在。终端再认证绑定当前管理员会话，默认界面最长 15 分钟，协议最多 30 分钟，空闲五分钟、Agent 断线十秒触发停止。输入输出、尺寸调整、Ctrl+C 和 Ctrl+D 是 PTY 操作，不使用远程命令任务。systemd cgroup 清理确认前不会显示停止成功；重启不自动恢复旧会话。Agent 退役持有执行屏障，等待日常操作结束并停止所有受管终端 cgroup，核对后才允许清理确认。浏览器当前是基础 `TERM=dumb` 文本终端，尚无全屏应用终端模拟器、录屏回放和跨平台 PTY。

面板运维健康页提供数据库大小/连接、后台队列积压、通知待投递/失败和已连接设备数量。系统自检 `/api/control-center/health` 按所有者权限集中展示宿主磁盘容量、各后台执行器的实际周期心跳、备份与恢复演练记录、签名制品库存及独立观察点提交证据；过期心跳、失败与未知分别显示。独立观察点可检查 `/healthz`，授权检查 `/api/fleet/health`，或者按管理 API 提交外部观察，不把队列无积压解释为健康。

Agent 日常操作使用共同执行互斥锁；等待后重新读取本机授权和期限，避免服务、文件、网络、证书变更并发。任何未知结果均不自动重放副作用操作。源码实现没有替代诊断实机门禁，也没有触发真实服务器、DNS、云资源或通知操作。

## 集成接口

面板 `fleet::router()` 提供 `/api/servers/{id}/fleet`、`/lifecycle`、`/costs`、`/migration-preview`、`/migrate`、`/events`、`/compare`、`/operations`、`/config-history` 与 `/terminals`。操作结果通过 `/api/fleet/operations/{id}` 查询；终端通过 `/api/fleet/terminals/{id}` 获取/请求关闭、`/input` 发输入。Agent 使用独立 `/api/agent/v1/fleet/work`、`/results`、`/terminal-events`，完成回执不因维护阻断。

强类型操作、结果与文件历史按实际能力授权，聚合操作历史只返回元数据。异步设备操作暂不接受 API 令牌，避免排队后令牌撤销仍借管理员权限执行；管理员任务领取时重新检查当前范围，并将排队授权快照与当前服务器 policy 再取交集；当前授权收窄或撤销不能被旧快照扩大。管理员终端绑定确切会话散列而非任意同账号会话。

独立日常操作未知核对使用 `/api/fleet/operations/{id}/inspection` 自动生成相应文件元数据、服务状态、监听、网络库存/受管状态或证书公开指纹检查。该检查不重放原动作；失败或超过五分钟的证据不能解除阻塞。`/reconcile` 要求近期会话、当前服务器/原能力/只读能力与 operations:write、成功的最新设备回执、明确失败或未知的人工结论、原执行已停止和临时资源清理的人工确认。人工核对只写独立 reconciliation 记录与时间，原操作状态/结果摘要继续保留，迟到的真实设备回执仍可写入；不把人工确认当成 Agent 成功。自动化所属步骤使用作业自身同事务证据核对。PTY 断线/退役清理与 Linux 受管文件的完整设备场景继续独立验收。

看板的实际管理员/API 令牌必须具有 monitoring:read 与对应服务器范围；只具监控权限时使用监控白名单，不返回采购费用、设备公钥、内部地址或受管进程详情。完整私有服务器字段另需 servers:read，拨测私有目标及执行来源另需 network:read。已认证但范围不足不会借匿名展示扩大范围，隐藏服务器始终排除。

服务器运维界面从当前管理员接口读取角色、功能与服务器范围，权限刷新失败时阻止提交。只读角色禁用资产保存、生命周期、费用、迁移确认、接入登记、文件保存、服务修改、终端输入和人工结束未知结果；已获对应读取授权的账号仍可获取系统快照、监听、服务状态、日志与原始文件。所有者的功能权限隐式具备，服务器范围仍采用接口实际授权；运维角色逐项授权。文件与服务控件还核对设备声明能力、面板目录/服务范围及大小预算，终端连接同时需要读取输出和执行输入授权。设备执行时继续核对本机策略交集和当前权限，界面禁用不替代后端授权。

## 集中验证

实现阶段冻结后，协议的默认关闭与强类型字段拒绝、日常操作授权与身份保护、文件路径穿越和软链接拒绝、真实 Descriptor 服务单元及未安装账号保持未知的回归已通过。Snapshot、Services 和 Ports 使用空结构体变体；现有仅含 kind 的 JSON 保持兼容，多余字段明确拒绝。CPU 硬限制预命令同时检查 seccomp 与实际 cpu.max，合规上限、放宽上限、无限/缺失上限与过滤不足的回归均已通过。

隔离 Linux-root 用例实际解析非 root NSS 账号并降权，证明 root 可写的 0700 证书目录不会被误报为运行时可读写；此方法单独记为通过，不更改默认 workspace 忽略数量。完整集中结果、源码与最新制品身份及仍需真实设备签收的范围统一见[平台集中验收](acceptance/operations-platform-expansion.md)。
