# 历史 NodeQuality 制品的源码身份

这三份文件保留本轮修改前的精确原字节，仅用于重建并严格校验已签名 r19、r20、r21 和 native-offline-r1 的兼容素材。它们不是测试缓存或待运行工具；当前默认构建使用外层 r22 源码，不读取这里的 runner/report。rootfs 历史文件用于既有离线制品的原身份，当前 IPQuality 元数据修复使用外层 rootfs.py。

`tools/nodequality_history.py` 固定每份文件的 SHA256，以普通文件、大小限制和不跟随输入链接的方式读入。历史源码只能按实际版本使用；禁止将 r22 当前字节改标为 r19，或改变这里的快照以使旧签名验证通过。完整执行门禁和工具许可条件继续有效。
